Before writing a JSON transformation, inspect the response that actually arrived. fx 40 introduced live interactive queries and key completion; 40.0.1 is a maintenance release.

A short workflow: open a captured response, explore its structure, preserve a useful JavaScript expression, and test what happens with missing fields or unexpected types. Extracting ten records does not prove the API should have returned ten.
