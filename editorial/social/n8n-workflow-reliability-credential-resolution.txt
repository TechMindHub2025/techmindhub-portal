n8n 2.46.5 is a reminder that workflow reliability depends on how the system translates configuration into action.

The release corrects credential lookup while loading node parameters and direct reads of named properties attached to arrays. It also hides archived workflows from migration-report totals by default while retaining their findings for inspection. The array fix has a specific boundary: returning the whole array can still lose named properties in isolated expression engines.

For an upgrade, test the exact credential context, expression and downstream operation, and record which workflows are included in the report. These are corrective changes; the release does not establish an exploitable vulnerability or publish a security advisory.
