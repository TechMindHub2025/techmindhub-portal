An AI agent can cross a security boundary when untrusted context becomes a privileged tool action. Microsoft's Defender update places inspection inside the local agent runtime and describes alerting or blocking for supported Windows scenarios.

Coverage depends on the particular agent, inspection method and configuration. We examine the control point, the documented support matrix and the tests a security team needs before treating runtime protection as an effective safeguard.
