GitHub Enterprise Server 3.23's release candidate introduces a preview of AI detection for unstructured secrets on the appliance's CPU. GitHub says it needs no hosted LLM, GPU or outbound connection, making it relevant to air-gapped development environments.

The same release expands known-malicious-package advisories and gives Dependabot a default three-day cooldown before version-update pull requests. These are separate controls with different limits. The release candidate and secret detector still need evaluation against real workloads and detection quality.
