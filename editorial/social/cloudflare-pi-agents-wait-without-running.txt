An AI agent waiting for approval should not need to keep a compute invocation alive. Cloudflare's Pi 1.6 integration lets a tool park until a signal, deadline or another session's result. Its Durable Object can hibernate while the agent's state remains available for resumption.

This is an execution architecture change, not a universal cost-saving claim. Storage, wakeups and model calls still matter, and the new transcript format complicates rollback to Pi 1.5. How does your agent system handle long waits without losing context or duplicating work?
