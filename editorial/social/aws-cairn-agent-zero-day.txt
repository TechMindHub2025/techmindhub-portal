AWS observed an attacker use Cairn agents to map a medical-imaging API and reach an arbitrary file write in roughly eleven minutes. Root access came in a later session. The decisive issue was the application boundary: a remote caller could affect server-side file placement. AWS assesses a Chinese nexus with moderate confidence; the trace does not establish the degree of autonomy in every later step.

For defenders, path constraints, process privilege and reconstruction of API probe sequences matter more than recognizing an agent name. What telemetry would reveal a transition from exploration to a file-write primitive?
